## Pendiente opcional — Set Némesis de Spider-Man

El listado del Core Set confirma que, al jugar con Spider-Man (con
independencia del villano), su set encuentro propio también forma
parte de la partida:
- Una carta de Obligación ("Aviso de desahucio" / *Eviction Notice*).
- Un set Némesis centrado en el Buitre: side scheme ("Ladrón Alado"),
  esbirro (Buitre) y dos Perfidias ("Picado arrollador", "Los planes
  del Buitre"), que "Una sombra del pasado" (arriba) puede introducir
  en juego.

No es imprescindible para el MVP (el motor puede funcionar sin él),
pero para que la partida Spider-Man vs. Rhino sea fiel al juego real,
este set debería añadirse en algún momento antes de dar por cerrada la
Fase 4. Decide tú si lo sacamos ahora o lo dejamos para más adelante.

## Notas de implementación

- "¡Soy duro!", "Difícil de tumbar" y "Estampida" son buenos primeros
  candidatos para el sistema de Effects de la Fase 3, porque su lógica
  es simple y genérica (dar estado, curar condicional, atacar condicional).
- "Piel blindada del Rino" y "Embestida" van a necesitar el modelo de
  Forced Interrupt descrito como pendiente en rules-spec.md, porque
  modifican el daño antes de que se aplique.
- Ninguna carta del set de Rhino interactúa con la mano o los recursos
  del jugador. "Con la guardia baja" (set Standard) es la primera
  excepción real: obliga a descartar un upgrade o support **en juego**.
  Para resolverla correctamente, el motor en modelo compañero necesita
  saber qué upgrades/supports tiene el jugador sobre la mesa, aunque
  no necesite conocer su mano ni sus recursos.
- "Una sombra del pasado" depende del héroe elegido (introduce su set
  némesis), así que su implementación no puede ser genérica: el motor
  necesita saber qué héroe se está jugando para saber qué set némesis
  cargar.
- Para el `id` interno de cada carta en el motor, usar el código
  numérico (ej. `01094`), no el nombre — así un futuro cambio de idioma
  en la interfaz no afecta a las referencias internas.
